#  Personal Portfolio Website

A responsive personal portfolio website developed as part of the **Oasis Infobyte Web Development Internship (OIBSIP)**. The website showcases my skills, projects, and professional profile in a clean, modern, and user-friendly design.

## Project Overview

The goal of this project is to create a personal online presence where visitors can learn about me, explore my technical skills, view my projects, and find ways to connect with me.

## Features

- **Responsive Design:** Adapts to desktop, tablet, and mobile screen sizes.
- **Hero Section:** Introduces me and highlights my role as an aspiring developer.
- **About Me:** Provides information about my background and interests.
- **Skills Section:** Showcases my technical skills and areas of learning.
- **Projects Section:** Displays selected projects with descriptions and links.
- **Contact Section:** Makes it easier for visitors to connect with me.
- **Modern UI:** Clean layout, attractive styling, and intuitive navigation.
- **Smooth Navigation:** Allows visitors to move between sections easily.

##  Technologies Used

- **HTML5** — website structure and semantic elements.
- **CSS3** — styling, layouts, animations, and responsiveness.
- **JavaScript** — interactive elements and navigation, where implemented.
- **Git and GitHub** — version control and project hosting.

## Getting Started

### Run Locally

1. Clone or download this repository.
2. Open the project folder in your code editor.
3. Open `index.html` in your web browser.
4. Explore the portfolio and test the navigation and interactive features.

No backend setup is required for a static portfolio website.
